# Documentation

Documentation for the **melodie_docs** repository — a small PHP site hosted on a MIKR.US VPS that serves two independent features:

1. **MMN (Melodie Mgieł Nocnych) player** — archives and plays recordings of a radio show, with per-recording playlists scraped from a blog.
2. **Przepisy (Recipes)** — a recipe browser, available in two versions (PDF-based v1, Markdown-based v2).

See the pages below for details:

- [architecture.md](architecture.md) — overall structure, request flow, and data layout.
- [mmn-player.md](mmn-player.md) — audio archive, radio page, recording/cleanup scripts, playlist scraper.
- [przepisy.md](przepisy.md) — recipe browser (v1 and v2) and content format.
- [scripts.md](scripts.md) — shell/Python automation scripts and cron usage.
- [deployment.md](deployment.md) — hosting, file layout on the server, and setup notes.
